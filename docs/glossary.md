# Risk Platform Glossary

Terms used across the codebase, collected so docs and code stay consistent.

- **Exposure** — the amount at risk for a given position or entity at a point in time.
- **Limit** — the configured maximum exposure a policy allows.
- **Threshold** — a boundary used by the risk engine to classify a signal.
- **Evaluation** — one run of the risk engine over a given input set.
- **Contract** — the agreed schema shared between the engine and its consumers.
- **Runbook** — an operational procedure for handling production events.

When adding a new term, define it here first, then use it in code comments.
